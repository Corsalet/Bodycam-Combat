# Bodycam Combat — Godot 4.3 порт (web)

Тактический шутер с захватом точек: RU против US, 10 минут, боты, всё офлайн.
Это WASM-сборка Godot-порта; для запуска локально открывай index.html только через сервер.

- Игра: https://<ИМЯ>.github.io/bodycam-combat/ (после включения Pages)
- Обновление: заменить index.pck в репозитории — wasm/движок не меняются, у игроков докачается только 77 КБ.

## Управление
WASD — движение • SHIFT — спринт • ЛКМ — огонь • ПКМ — прицел/оптика • R — перезарядка • 1/2 — оружие • 3 — бинт • ESC — пауза
