# BODYCAM // ОПЕРАЦИЯ «КАРАКУМ»

Реалистичный тактический шутер от первого лица в эстетике «bodycam» (нагрудная камера: зерно, REC, таймкод, виньетка, ручное качание камеры). Всё в одном HTML-файле + локальные three.js и GLB-модели — без сборки и без внешних CDN.

**Играть:** https://corsalet.github.io/Bodycam-Combat/

## Режим

- **Захват точек (оффлайн с ботами):** 3 точки — A «Хутор», B «Депо», C «Блокпост».
- Карта — большая пустынная (~440×440 м): хутор, депо с ангаром, блокпост с вышками, базы сторон, грунтовки, укрытия (контейнеры, HESCO, мешки с песком, скалы).
- Раунд — **10 минут**. У каждой стороны 250 билетов; большинство точек «кровоточит» билеты противника, каждое убийство списывает 1 билет. Конец — по билетам или по времени.
- Боты: 6 союзников + 7 противников; ИИ продвигается к точкам, устраивает засады у укрытий, стреляет очередями, отступает при потере видимости.

## Стороны и классы

| Сторона | Штурмовик | Снайпер |
|---|---|---|
| **РОССИЯ** | АК-74 + ПМ | СВД Драгунова + ПМ |
| **США** | М16А4 + Desert Eagle .50 | M82A1 Barrett + Desert Eagle .50 |

Модели оружия и солдат — реальные low-poly GLB (в `assets/`), viewmodel от первого лица, прицел с плавным зумом, у снайперок — полноэкранная оптика (ПКМ).

## Управление

- **WASD** — движение, **SHIFT** — спринт, **SPACE** — прыжок
- **ЛКМ** — огонь, **ПКМ** — прицел/оптика (удерживать)
- **R** — перезарядка, **1/2/колесо** — смена оружия
- **ESC** — пауза

## Технологии

- three.js r128 (локально), GLTFLoader + SkeletonUtils (r128); каждый бот — собственный экземпляр солдата с перепривязанным скелетом
- Процедурный звук (WebAudio): выстрелы у каждого ствола свои, свист пуль, ветер
- Оффлайн-точки интеграции помечены `NET:` — онлайн (PeerJS) подключается позже: `NET.connect(roomId)`, снапшоты `NET.buildSnapshot()`, удалённые игроки `NET.spawnRemote()`

## Версии

- **v0.1.7 (BUILD 8)** — оружие перестало быть чёрным силуэтом: у исходных GLB (СВД/АК/М16/Макаров/Дэгл) нет текстур, а baseColor-факторы задраны в 2-8% яркости; материалы без текстур нормализуются к видимой яркости с сохранением оттенков (дерево/металл/оптика), некрашеный белый — в сталь; М82 с текстурой не тронута; вид один и для viewmodel, и для ботов (общие материалы);
  - - **v0.1.6 (BUILD 7)** — шестой плейтест:
  - стволы наведены в перекрёсток ПОЗИЦИОНЫМ выводом дула (дуло-конец = hipPos − len/2·scale): СВД (50%, 57%), М82 (53%, 54%), М16 (59%, 61%); АК-74 не тронут (был норм); выяснено: vmPitch/hipYaw рендером не применяются, у СВД/М16 исходное дуло модели на +Z (flip:true), у М82 — на −Z (flip:false);
  - вспышка выстрела перенесена с holder на wrap — светится ровно у дульного среза;
  - версия и сборка показываются в HUD (строка REC);
  - - **v0.1.5 (BUILD 6)** — пятый плейтест:
  - оружие «наведено»: дуло всех винтовок выведено в перекрёсток (проверено дульной сферой-маркером по кадрам), приклад с магазином крупно у правого плеча; М16А4 — ориентация исправлена (тонкая труба приклада обманула автодетект так же, как у СВД — теперь flip true), АК-74/M82 перепосажены под «стреляющий» вид;
  - боты: выход из «карманов» — при полном пине перебор 16 направлений по кругу до свободного; подтверждён полный обход самого большого здания;
  - v0.1.4 (BUILD 5)
  - viewmodel'ы: у СВД автоматика нормализации разворачивала модель дулом в камеру (рамочный приклад и ствол у СВД одинаково тонкие — автодетект путался) — теперь дуло наружу, приклад крупно у правого плеча, ствол с оптикой идёт вверх к перекрёстку; М16 снова видна (frustumCulled=false для всех viewmodel'ов); телепорт взгляда (debug) больше не качает оружие;
  - боты: полноценное следование вдоль стен — выбирают сторону обхода по свободному «усу» и идут вокруг препятствия, пока путь к цели не очистится; при застревании меняют сторону; заходят на точку с флангов (свой боковой офсет у каждого бота), при HP < 35 коротко отступают спиной;
  - v0.1.3 (BUILD 4)
  - СВД больше не «лежит»: у модели дуло смотрело в камеру (рамочный приклад обманул автодетект стороны) + неправильная посадка. Теперь: дуло −Z, приклад крупно у правого плеча, ствол с оптикой идёт к перекрёстку; для длинных стволов добавлен vmScale (влезает в кадр вместе с прикладом); АДС плавно выравнивает наклон;
  - пассивный хил убран: лечение — бинтами (слот «3», 5 шт., перебинтовка 2.6 с, +55 HP, на время перебинтовки оружие опущено, стрельба/перезарядка/АДС заблокированы), счётчик в HUD;
  - боты: выталкивание из коллайдеров, детект застревания, обходной манёвр с запоминанием стороны, скольжение вдоль стен — в стены больше не втыкаются;
  - v0.1.2 (BUILD 3) — фиксы второго плейтеста:
  - боты больше не идут боком (ось «вперёд» модели солдата — +Z, а не +X; проверено по вектору носок стопы→палец);
  - «растянутые руки» у ботов — это были горизонтально торчащие стволы: оружие пересажено в руки (кисти у живота, ствол вперёд-вверх), стойка «несёт оружие» вместо рук по швам;
  - viewmodel СВД/М16/M82A1 больше не «открепляется и летает вдали» (приклад длинных стволов уходил за нижний край кадра, виднелся только дальний кусок ствола) — теперь классическая посадка: приклад крупно у бедра, ствол с наклоном (hipYaw/vmPitch) идёт к центру кадра;
  - viewmodel АК-74 оставлен без изменений (v0.1.1).
- **v0.1.1 (BUILD 2)** — большой патч по результатам плейтеста:
  - viewmodel длинных стволов отодвинут от камеры (АК-74 больше не «в упор»), АК-74 развернут правильной стороной (магазин вниз);
  - у ботов появилась **процедурная скелетная анимация**: ходьба с махами рук, стойка с оружием, прицеливание в бою, дыхание в покое — T-поза убрана (в модели солдата анимация отсутствует, а флаг skinning при замене материалов был потерян);
  - боты **держат оружие в руках** (свой экземпляр ствола у каждого, вспышки и трассеры их выстрелов видны);
  - **боты воюют между собой** (фраги засчитываются, лента убийств пополняется);
  - поведение на точках: у каждого бота своё место у точки, остановка и осмотр вместо «хороводов», расталкивание ботов;
  - «летающие патроны» рядом с АК-74 удалены (геометрический фильтр оторванных мешей).
- **v0.1.0 (BUILD 1)** — первый релиз: меню (сторона/класс), режим захвата, боты, 6 стволов, bodycam-эстетика, заготовки NET.

## Запуск локально

```
python3 -m http.server 8000
# открыть http://localhost:8000
```

Любой статический сервер подходит (fetch GLB требует http://, не file://).
